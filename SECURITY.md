# Security

## Reporting a vulnerability

Please report security problems in Visemate **privately**, never in public:

1. Open this repository's **[Security](https://github.com/Radowan30/visemate-releases/security)** tab.
2. Choose **Report a vulnerability**, and describe what you found, how to reproduce it, and which release you
   installed.

Only the maintainers can read the report. We will acknowledge it, keep you informed while it is fixed, and credit
you in the release notes if you would like.

Please do not look at, change or keep anybody else's data while investigating. Stop as soon as you can show the
problem, and tell us what you accessed.

## Supported versions

Only the [latest release](https://github.com/Radowan30/visemate-releases/releases/latest) receives fixes. When a fix
must reach everybody, older versions are retired: they show an **Update Visemate** screen and can no longer connect
until they are updated.

## Installing Visemate safely

- Install only from this repository's releases, from [visemate.app/download](https://visemate.app/download), or
  from the app's **Update now** button.
- Each release's notes give the APK's SHA-256 checksum and the fingerprint of the key that signed it. The
  [README](README.md#check-your-download) shows how to check them.
- Android refuses to install an update signed with a different key, so a tampered copy cannot replace a genuine
  installation.
